SUPPORT & FAQ

Frequently Asked Questions

Can I run Open-Dot completely offline without an API key?

Yes! Open-Dot seamlessly integrates with Ollama. Simply launch Ollama locally, and Open-Dot will detect your local models (Llama 3, Qwen, DeepSeek) for 100% private inference.

How does Open-Dot handle multi-agent execution?

Open-Dot uses a subagent dispatcher that launches isolated background subagents. Each subagent runs with its own prompt, context budget, and scoped tool permissions.

What operating systems are supported?

Open-Dot runs natively on Windows, macOS, and Linux via Node.js CLI and Electron Desktop app packaging.

How does Open-Dot verify code edits?

Open-Dot follows a strict zero-hallucination verification rule: after editing files, it automatically executes `tsc --noEmit`, unit tests, or build commands to empirically verify clean success.
