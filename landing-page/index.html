Nothing risky runs without a yes.

Small models make mistakes, so the app, not the model, decides what is allowed.

  • Approval cards for commands and anything that changes your files.
  • Private addresses blocked. Pages cannot send a dot to localhost or your home network.
  • Links must be real. A link in an answer has to come from a page the dot actually opened.
  • Secrets stay sealed with Windows DPAPI or the macOS Keychain.

Running in five commands.

You need Node 20 or newer, pnpm and Ollama.

# get the code
$ git clone https://github.com/VedantJadhav701/opendot-local
$ cd opendot-local && pnpm install

# get the model (about 2.5 GB) and the browser
$ ollama pull qwen3:4b-instruct-2507-q4_K_M
$ pnpm exec playwright install chromium

# start
$ pnpm dev

Open http://localhost:3000. If a step fails, open an issue on GitHub with the error text.

Questions.

Is it really free?

Yes. The app is open source and the models run on your hardware through Ollama. There is no account and no API key. The optional cloud model is off until you add your own key.

What computer do I need?

Any machine capable of running Ollama locally. From standard laptops running 4B models up to workstation rigs or DGX servers running 27B+ models, OpenDot-local adapts seamlessly to your hardware.

Does my data leave my computer?

No, unless you turn on the optional cloud model. Pages you open are fetched from the web, and what a dot reads is stored in a local database.

How does context handling work?

Dots read full web pages, PDFs, and files, store them locally, and retrieve precise passages for the model. This keeps your local inference fast and accurate regardless of model size.

Which models can I use?

Any model you pull in Ollama — from 4B models up to 27B, 70B, or custom GGUFs. You choose the best model for your hardware.

Can I help?

Yes. Try it, open issues, and send pull requests. Benchmarks on different hardware are especially useful.
