## 2. API Catalog Terms & Restrictions

### A. Non-Affiliation Disclaimer
OpenDot Local is an independent local-first open-source application. It is **not affiliated with, endorsed by, or sponsored by NVIDIA Corporation, OpenAI, or Ollama**.

### B. Usage & Training Restrictions
1. **Model Output Distillation**: Per the NVIDIA API Catalog Terms of Service and Meta Llama 3.1 Community License, outputs generated by `meta/llama-3.1-70b-instruct` **must not be used to train, fine-tune, or improve non-Llama competitor AI models**.
2. **Acceptable Use**: All cloud completion requests must comply with the [Meta Llama Acceptable Use Policy](https://llama.meta.com/use-policy).

### C. Rate Limits & Quotas
- **Default Free Trial Rate Limit**: ~40 Requests Per Minute (RPM), max 10 concurrent requests.
- **Backoff Protocol**: Returns HTTP 429 status code with standard `Retry-After` response header when rate limit is exceeded.
- **Per-Turn Budget**: OpenDot Local enforces a default limit of 5 cloud API calls per agent turn to prevent unexpected quota depletion.
