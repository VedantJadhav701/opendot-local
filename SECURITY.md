# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

Security and user privacy are foundational priorities for OpenDot-local. If you discover a security vulnerability, please report it privately rather than opening a public issue.

To report a vulnerability, please email **verdantjadhav26@gmail.com** with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix or mitigation

You will receive an acknowledgment within 48 hours, followed by updates as we work on a fix.
